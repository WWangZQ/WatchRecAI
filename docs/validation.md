## 尚未覆盖

- **真实手表验收**：本轮没有安装 APK；手表上的文字输入、屏幕适配、麦克风权限、长时间后台录音、断网重试和与电脑直传仍需在预览设备上实测。APK 编译和单元测试不能代替这些检查。
- **真实 Linux 部署**：VPS API 用本地临时进程和测试客户端验证。systemd、Docker Compose、云厂商防火墙、NAT、Caddy 证书签发没有在一台新的真实 Linux VPS 上验收。
- **完整首次模型下载**：联网下载能够开始，但本轮下载过慢，未等待约 893 MB 权重重新下载完。功能测试使用从现有模型缓存复制到验证目录的模型文件；未修改原缓存。新用户第一次完整下载的时间与网络条件需另行验证。
- **GPU 与其他操作系统**：便携包为 Windows x64 CPU 版；源码中的 CUDA 自动选择已实现，但没有在这份新副本里做 GPU 实际转写；未构建 macOS/Linux 桌面包。
- **长录音与 AI 服务**：保留原版本的大文件与 AI 断点续跑逻辑，本轮没有重跑数小时个人录音，也没有消费真实 AI API 配额。
- **签名与正式发布**：本次发布为 GitHub Pre-release，尚不属于稳定版。APK 使用调试签名，EXE 没有商业代码签名。原源码快照没有项目级 LICENSE 文件，本轮没有代替维护者选择授权条款。

首次使用前，建议用一条十几秒录音完成 README 的三端验收，再尝试长录音。验证材料保存在开发副本的 `.verification/`，不会进入分发压缩包。
